# 错题分发功能 - 需求文档

## 1. 功能概述

上传记录中的图片经识别后，需要分发为错题记录。分发是将上传记录中的图片转化为错题的过程，包含学科、年级、图片等信息的传递。

分发有两个触发来源：
- **自动分发**：VL 图片分析完成后，系统自动将分组结果分发为错题
- **手动分发**：管理员在管理端手动选择图片、指定学科和年级后，分发为错题

## 2. 触发场景

### 2.1 自动分发

**触发时机**：学生上传图片后，VL 分析服务完成学科/年级识别和图片分组

**流程**：
1. VL 分析返回分组结果（每组包含图片索引、学科、年级、描述）
2. 系统按分组逐个创建错题记录
3. 每组图片对应一条错题，学科和年级来自 VL 识别结果
4. 全部分发完成后，上传记录状态标记为"已完成"

**失败处理**：
- VL 分析失败时，上传记录标记为"已完成"，等待管理员手动处理
- 单个分组分发失败不影响其他分组，记录警告日志

### 2.2 手动分发

**触发时机**：管理员在管理端查看上传记录，手动将图片指派为错题

**流程**：
1. 管理员选择上传记录中的部分或全部图片
2. 管理员指定学科和年级（必填）
3. 管理员可添加备注
4. 系统创建错题记录
5. 分发完成后，上传记录状态标记为"已完成"

**多分组支持**：
- 管理员可一次将图片分为多个组，每组独立指定学科和年级
- 未被分配的图片不计入错题

## 3. 分发接口需求

### 3.1 输入参数

| 参数 | 必填 | 说明 |
|------|------|------|
| 学生ID | 是 | 错题所属学生 |
| 学科 | 是 | 学科编号（1-9） |
| 年级 | 是 | 年级编号（1-12） |
| 图片路径列表 | 是 | 至少包含一张图片的 OSS 路径 |
| 备注 | 否 | 补充说明 |
| 来源上传记录ID | 是 | 关联的上传记录，用于追溯 |

### 3.2 输出结果

| 字段 | 说明 |
|------|------|
| 是否成功 | 分发是否成功 |
| 错误信息 | 失败时的原因描述 |
| 创建的错题ID列表 | 成功创建的错题记录ID |

### 3.3 业务规则

**参数校验**：
- 学生ID 不能为空
- 学科必须在 1-9 范围内
- 年级必须在 1-12 范围内
- 图片路径列表不能为空
- 来源上传记录ID 不能为空

**错题初始状态**：
- 新创建的错题状态为"待审核"

## 4. 分发后的关联关系

- 错题通过 `sourceUploadId` 字段关联到原始上传记录
- 错题通过 `sourceRegions` 记录每张图片的 OSS 路径
- 一个上传记录可对应多条错题（多组分发）
- 管理端可通过上传记录ID 查询其关联的所有错题

## 5. 约束

- 分发操作不可撤销（创建的错题需通过审核流程管理）
- 图片路径必须为 OSS 上已存在的有效路径
- 自动分发和手动分发使用同一个分发接口，保证行为一致

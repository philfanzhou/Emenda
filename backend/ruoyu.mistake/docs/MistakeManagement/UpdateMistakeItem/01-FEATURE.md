# 错题条目更新 (UpdateMistakeItem)

## 功能名称和一句话概括

错题条目更新 — 教师通过 gRPC 接口对已有错题条目进行部分字段更新，支持修改学生 ID、学科、年级和来源图片区域，系统先查后改并返回更新后的完整错题信息。

## 核心用户故事

1. **教师修改错题条目信息**：作为教师，当发现错题条目的学生归属、学科、年级或图片区域需要调整时，我可以通过指定条目 ID 并传入需要修改的字段来进行部分更新，系统自动保留未传入的字段不变。

2. **更新后立即查看结果**：作为教师，更新完成后系统返回最新的完整错题条目信息，让我能够立即确认修改是否生效。

## 关键验收条件摘要

- AC-1：更新前必须先通过 ID 查找条目，条目不存在时返回 NotFound 错误。
- AC-2：支持部分更新——仅传入非空/非零值的字段会被更新，未传入的字段保持不变。
- AC-3：更新成功后返回包含所有最新字段的完整 MistakeItemDto。
- AC-4：student_id 仅当非空时才更新；grade 仅当 > 0 时才更新；subject 仅当 > 0 时才更新；source_regions 仅当 count > 0 时才更新。

## 明确列出"范围外"（不做什么）

- 不处理错题条目字段校验（subject 0-9、grade 0-12 等校验不在更新方法中执行）。
- 不验证 student_id 是否在 ruoyu.student 服务中真实存在。
- 不处理错题的创建、删除、查询（分别由 AddMistakeItem、DeleteMistakeItem、GetMistakeItem 模块负责）。
- 不自动记录操作日志（更新操作不写入 process_log）。

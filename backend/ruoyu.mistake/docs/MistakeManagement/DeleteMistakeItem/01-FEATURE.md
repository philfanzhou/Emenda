# 错题条目删除 (DeleteMistakeItem)

## 功能名称和一句话概括

错题条目删除 — 教师通过 gRPC 接口删除指定的错题条目，系统自动清理关联的练习记录和操作日志，在一次事务中完成级联删除。

## 核心用户故事

1. **教师删除错题条目**：作为教师，当某条错题不再需要时，我可以通过条目 ID 删除该错题条目，系统自动清理所有关联的练习记录和操作日志，确保数据一致性。

2. **级联清理保证数据完整性**：作为系统管理员，删除错题条目时我不希望留下孤立的练习记录或操作日志数据，系统应在同一事务中完成所有关联数据的清理。

## 关键验收条件摘要

- AC-1：根据 ID 查找条目，条目不存在时返回 success=false（不抛出异常）。
- AC-2：删除流程依次执行：删除关联的练习记录 → 删除关联的操作日志 → 删除错题条目自身。
- AC-3：所有删除操作在同一事务中提交，任何一步失败都应回滚。
- AC-4：删除成功后返回 BoolResponse { Success = true }。

## 明确列出"范围外"（不做什么）

- 不删除关联的 OSS 图片文件（图片清理由专门的清理流程负责）。
- 不验证条目是否处于特定审核状态（任意状态的条目均可删除）。
- 不做软删除（逻辑删除），仅做物理删除。
- 不处理错题的创建、更新、查询（分别由 AddMistakeItem、UpdateMistakeItem、GetMistakeItem 模块负责）。

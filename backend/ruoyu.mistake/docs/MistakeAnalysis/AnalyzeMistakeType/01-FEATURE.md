# 错题类型分析 (AnalyzeMistakeType)

## 功能名称和一句话概括

错题类型分析 — 对指定错题条目进行错误类型分析，基于答案对比返回错误分类结果（类型编号、类型名称、分析原因），并通过 gRPC 暴露接口。

## 核心用户故事

1. **教师查看错题类型**：作为教师，我希望对一条错题记录调用分析接口，系统自动对比正确答案与学生答案，返回该题的错误类型分类（如计算错误、概念混淆等），帮助我快速了解学生的薄弱环节。

2. **系统自动分类**：作为系统，当错题被创建或审核确认后，我希望自动触发类型分析，将分析结果与错题条目关联存储，为后续的数据统计和个性化推荐提供依据。

## 关键验收条件摘要

- AC-1：传入合法的 `mistake_item_id` 后，返回包含 `type`（数字）、`type_name`（字符串）、`analysis_reason`（字符串）的响应。
- AC-2：当错题条目存在时，分析完成后记录一条 `ProcessAction.Analyzed` 类型的处理日志。
- AC-3：`mistake_item_id` 必须为合法 GUID 格式，非法格式在 gRPC 层被拒绝。

## 明确列出"范围外"（不做什么）

- 不实现基于 AI/LLM 的错误类型智能分析（当前为硬编码占位实现，始终返回 type=5 "其他错误"）。
- 不实现分析结果的缓存机制。
- 不批量分析多条错题的错题类型。
- 不将分析结果持久化到错题条目的 `Type` 字段。
- 不处理教师对分析结果的修正或覆写。

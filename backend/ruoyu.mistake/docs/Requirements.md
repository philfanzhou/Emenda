# 错题本 gRPC 服务 - 需求文档

## 1. 项目概述

### 1.1 目的

本文档描述**错题本 gRPC 服务**的功能性需求，该服务是 Ruoyu.Study 教育平台的后端微服务，提供错题记录管理、审核流程、练习追踪和错题分析功能。

### 1.2 范围

本服务管理以下内容：
- 错题分发的自动与手动创建
- 错题的增删改查
- 错题审核流程（待审核 → 确认/驳回 → 整批完成）
- 错题练习记录追踪
- 错题类型分析
- 错题处理过程日志

### 1.3 外部依赖

本服务依赖以下外部服务：
- **ruoyu.student** 服务：提供学生档案信息和图片上传记录查询，审核完成后调用其 `RemoveImagesFromRecord` 清理图片
- **OSS (MinIO/SeaweedFS)**：存储错题原始图片和练习图片
- **VL 分析服务**（可选）：自动识别图片的学科/年级并进行分组

## 2. 功能需求

### 2.1 错题分发

#### FR-001 提交错题分发

接收来自上传记录的分发请求，创建错题记录。支持自动分发（VL 分析后）和手动分发（管理员操作）两种触发方式。

| 项目 | 说明 |
|------|------|
| **输入** | 学生ID (string, 必填), 学科 (int, 1-9), 年级 (int, 1-12), 图片路径列表 (repeated string, 至少1张), 备注 (string, 可选), 来源上传记录ID (string, 必填) |
| **输出** | 创建成功的错题ID列表 |
| **业务规则** | - 学生ID 不能为空 <br> - 学科必须在 1-9 范围内 <br> - 年级必须在 1-12 范围内 <br> - 图片路径列表不能为空 <br> - 新创建的错题状态为"待审核" <br> - 同 source_upload_id + 学生 + 学科 + 年级 的组合幂等：已存在则返回现有列表 |

#### FR-002 手动添加错题条目

管理员直接创建错题条目，不依赖上传记录的分发流程。

| 项目 | 说明 |
|------|------|
| **输入** | 学生ID (string, 必填), 学科 (int, 0-9), 年级 (int, 0-12), 来源上传记录ID (string, 必填), 图片区域列表 (repeated SourceRegion), 备注 (string, 可选) |
| **输出** | 创建的错题条目完整信息 |
| **业务规则** | - 学生ID 不能为空 <br> - 至少需要一个图片区域 <br> - 新创建的错题状态为"待审核" |

### 2.2 错题条目管理

#### FR-003 查询错题条目

根据 ID 查询单条错题条目。

| 项目 | 说明 |
|------|------|
| **输入** | ID (GUID, 必填) |
| **输出** | 错题条目完整信息或 NotFound 错误 |
| **业务规则** | - 错题不存在时返回 NotFound |

#### FR-004 按上传记录查询错题

根据来源上传记录 ID 查询其关联的所有错题条目。

| 项目 | 说明 |
|------|------|
| **输入** | 来源上传记录ID (string, 必填) |
| **输出** | 错题条目列表 |
| **业务规则** | - 无关联错题时返回空列表 |

#### FR-005 分页查询错题列表

支持按学生、学科、年级、审核状态筛选的分页查询。

| 项目 | 说明 |
|------|------|
| **输入** | 学生ID (string), 学科 (int), 年级 (int), 审核状态 (ReviewStatus), 页码 (int), 每页大小 (int) |
| **输出** | 错题条目列表 + 分页元信息 |
| **业务规则** | - 每页大小范围 1-100，默认 10 <br> - 页码从 1 开始 |

#### FR-006 更新错题条目

修改错题条目的学生、学科、年级、图片区域等信息。

| 项目 | 说明 |
|------|------|
| **输入** | 错题ID (GUID, 必填), 学生ID (string, 可选), 学科 (int, 可选), 年级 (int, 可选), 图片区域列表 (optional) |
| **输出** | 更新后的错题条目完整信息 |
| **业务规则** | - 错题必须存在 <br> - 仅更新提供的字段 |

#### FR-007 删除错题条目

删除错题条目及其关联的练习记录和处理日志。

| 项目 | 说明 |
|------|------|
| **输入** | ID (GUID, 必填) |
| **输出** | 布尔值成功响应 |
| **业务规则** | - 级联删除关联的练习记录 (mistake_practice) <br> - 级联删除关联的处理日志 (process_log) <br> - 错题不存在时返回 false（不报错）|

### 2.3 错题审核

#### FR-008 审核错题条目

对单条错题进行确认或驳回审核。审核时可修正学科和年级。

| 项目 | 说明 |
|------|------|
| **输入** | 错题ID (GUID, 必填), 审核状态 (Confirmed/Rejected), 审核人ID (string), 审核意见 (string), 年级 (int, 可选), 学科 (int, 可选) |
| **输出** | 布尔值成功响应 |
| **业务规则** | - 只能审核"待审核"状态的错题 <br> - 审核结果只能是确认或驳回 <br> - 审核确认/驳回后记录处理日志 <br> - 可在审核时修正年级（1-12）和学科（1-9） |

#### FR-009 查询待审核上传记录

分页查询存在待审核错题的来源上传记录，支持按学科筛选。

| 项目 | 说明 |
|------|------|
| **输入** | 页码 (int), 每页大小 (int), 学科列表 (repeated int, 可选) |
| **输出** | 待审核上传记录列表 + 分页元信息，每条包含来源上传ID、学生ID、学科、年级、待审核数、总数、最早创建时间 |
| **业务规则** | - 仅返回存在 PendingReview 状态错题的上传记录 <br> - 每页大小范围 1-100 |

#### FR-010 完成上传审核

对某条来源上传记录下的所有已完成审核的错题执行后处理：将已确认的错题图片从 `uploads/` 迁移到 `mistakes/`，并通知 Student 服务清理上传记录中的图片。

| 项目 | 说明 |
|------|------|
| **输入** | 来源上传记录ID (string, 必填), 审核人ID (string) |
| **输出** | 成功/失败响应 + 学生ID |
| **业务规则** | - 该上传记录下不能存在待审核的错题 <br> - 已确认的错题：复制 uploads/ → mistakes/ 并更新 source_regions 路径 <br> - 已驳回的错题：不复制图片 <br> - 跨服务调用 Student.RemoveImagesFromRecord 移除已处理的图片 |

### 2.4 错题练习

#### FR-011 添加练习记录

为已确认的错题添加练习记录。

| 项目 | 说明 |
|------|------|
| **输入** | 错题条目ID (GUID, 必填), 学生ID (string, 必填), 图片路径列表 (repeated string, 可选), 学生答案 (string), 是否正确 (bool), 备注 (string) |
| **输出** | 创建的练习记录完整信息 |
| **业务规则** | - 错题必须存在且为"已确认"状态 <br> - 记录处理日志 (Practiced) |

#### FR-012 查询练习记录

查询指定错题的所有练习记录。

| 项目 | 说明 |
|------|------|
| **输入** | 错题条目ID (GUID, 必填) |
| **输出** | 练习记录列表 |
| **业务规则** | - 无练习记录时返回空列表 |

### 2.5 错题分析

#### FR-013 分析错题类型

对指定错题进行类型分析，返回错题分类结果。

| 项目 | 说明 |
|------|------|
| **输入** | 错题条目ID (GUID, 必填) |
| **输出** | 错题类型编号、类型名称、分析原因 |
| **业务规则** | - 记录处理日志 (Analyzed) |

### 2.6 处理日志

#### FR-014 记录处理日志

为错题记录操作过程日志。

| 项目 | 说明 |
|------|------|
| **输入** | 错题条目ID (GUID, 必填), 学生ID (string), 操作类型 (ProcessAction), 详情 (string) |
| **输出** | 布尔值成功响应 |
| **业务规则** | - 错题必须存在 <br> - 操作类型包括：Created, Analyzed, ReviewConfirmed, ReviewRejected, Practiced, Mastered |

#### FR-015 查询处理历史

查询指定错题的所有处理日志。

| 项目 | 说明 |
|------|------|
| **输入** | 错题条目ID (GUID, 必填) |
| **输出** | 处理日志列表，按时间正序排列 |
| **业务规则** | - 无处理日志时返回空列表 |

### 2.7 图片路径查询

#### FR-016 获取所有引用图片路径

返回系统中所有被引用的图片 OSS 路径，用于 OSS 垃圾清理时的引用检查。

| 项目 | 说明 |
|------|------|
| **输入** | 无 |
| **输出** | 去重后的图片路径集合 |
| **业务规则** | - 包含 mistake_item.source_regions 和 mistake_practice.image_paths 中的所有路径 |

## 3. 非功能需求

### 3.1 性能

- gRPC 响应时间：简单查询 P95 < 100ms
- 数据库查询应使用适当的索引

### 3.2 可靠性

- 提供健康检查端点
- 使用正确的状态码优雅处理无效输入（InvalidArgument、NotFound、Internal）
- 审核完成操作涉及跨服务调用和 OSS 操作，单个图片迁移失败不阻塞整体流程

### 3.3 数据完整性

- 删除错题条目时级联删除练习记录和处理日志（数据库外键约束）
- 审核状态流转：PendingReview → Confirmed / Rejected
- 只有 Confirmed 状态的错题才能添加练习记录
- 同一 source_upload_id 下所有错题审核完成后才能执行 CompleteUploadReview

### 3.4 安全性

- 所有接口进行输入验证
- 错误使用正确的 gRPC 状态码
- 跨服务调用需处理网络异常

# 获取错题练习记录 (GetMistakePractices)

## 功能名称和一句话概括

获取错题练习记录 — 根据错题条目 ID 查询该错题的所有练习历史记录，按练习时间排序返回，基于 gRPC 暴露查询接口，从 PostgreSQL 直接读取。

## 核心用户故事

1. **学生查看练习历史**：作为学生，我希望查看某道错题的全部练习记录，包括每次练习的提交答案、是否正确、练习图片和备注，帮助我回顾学习历程。

2. **教师评估练习情况**：作为教师，我希望在错题详情页看到学生的完整练习历史，以便评估学生对这道错题的掌握程度和进步趋势。

## 关键验收条件摘要

- AC-1：传入有效的 `mistake_item_id`（GUID 格式），返回该错题的所有练习记录列表。
- AC-2：返回的每条练习记录包含 `id`、`mistake_item_id`、`student_id`、`practice_date`、`image_paths`、`student_answer`、`is_correct`、`comments` 完整字段。
- AC-3：若该错题没有练习记录，返回空列表（非错误）。
- AC-4：`id` 参数为非法 GUID 格式时，gRPC 层抛出解析异常。

## 明确列出"范围外"（不做什么）

- 不实现练习记录的分页查询（当前返回全部记录）。
- 不实现按学生 ID 或时间范围筛选练习记录。
- 不实现练习记录的排序参数配置（当前由仓储实现层决定排序）。
- 不实现练习统计或汇总（如正确率、练习次数等）。
- 不实现练习记录的修改和删除（仅通过 DeleteMistakeItem 级联删除）。

# 查询错题练习记录 (GetMistakePractices)

## 核心用户故事

作为教师或学生，我希望能够查看某条错题的所有练习记录，以便了解该错题的练习情况和掌握进度。

## 补充约束

- 查询结果按 `PracticeDate` 升序排列
- 无分页，返回全部练习记录
- 错题不存在时返回空列表（非错误）

## 关键验收条件摘要

- 根据错题 ID 返回所有关联的练习记录
- 结果按练习时间升序排列
- 无练习记录时返回空列表

## 范围外

- 分页查询
- 按学生筛选练习记录
- 按时间范围筛选

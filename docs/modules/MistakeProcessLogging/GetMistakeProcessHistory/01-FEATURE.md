# 错题处理历史查询 (GetMistakeProcessHistory)

## 核心用户故事

作为教师/学生，我希望查看某道错题的完整处理历史（创建、分析、审核、练习等），以便追踪错题从录入到掌握的全过程。

## 补充约束

- 无分页，返回指定错题的全部处理日志
- 按 `CreatedAt` 升序排列（时间线顺序）
- 不校验错题条目是否存在，即使错题已删除仍可查到其历史日志（取决于数据库外键约束策略）

## 关键验收条件摘要

1. 传入有效 mistakeItemId，返回该错题所有 ProcessLog，按时间升序
2. 传入不存在任何日志的 mistakeItemId，返回空列表
3. 日志中的 Action 字段映射为 ProcessAction 枚举值

## 范围外

- 不支持按 Action 类型过滤
- 不支持分页
- 不支持时间范围过滤
- 不校验 mistakeItemId 对应的错题条目是否存在
